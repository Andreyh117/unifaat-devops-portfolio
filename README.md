## Aprendizados

- Organizar mudanças em branches torna o histórico mais seguro e fácil de revisar.
- Commits pequenos, com mensagens no padrão Conventional Commits, deixam clara a evolução do projeto.
- Docker permite executar a aplicação no mesmo ambiente, independentemente do computador utilizado.
- Arquivos como `.gitignore` e `.dockerignore` evitam incluir dependências, credenciais e arquivos desnecessários.
